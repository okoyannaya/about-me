# Изменчивые факты проекта

- Версии и зависимости сверяй с `package.json` и фактическими импортами.
- Команды сверяй с `scripts` в `package.json`.
- Алиасы сверяй с `tsconfig.json`.
- Структуру сверяй с фактически существующими непустыми каталогами.
- Если пользователь поручил изменить зависимости, используй пакетный менеджер и не редактируй lock-файл вручную.
