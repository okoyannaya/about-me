# Изменчивые факты проекта

- Перед обновлением технологического стека сверяй `package.json`, конфигурацию и фактические импорты.
- Для изменчивых подробностей указывай источник истины: `tsconfig.json` для алиасов, `package.json` для версий.
- Если пользователь поручил удалить неиспользуемую зависимость, используй пакетный менеджер и не редактируй lock-файл вручную.
