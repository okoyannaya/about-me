# Реактивность

- Исходное состояние храни в `signal()`, производное вычисляй через `computed()`.
- `effect()` используй для побочных действий, а не вместо производных значений.
- Реактивные объекты обновляй без прямой мутации.
- Observable подключай к представлению через `async` или один переиспользуемый `toSignal()`.
- Ручные подписки ограничивай через `takeUntilDestroyed()`.
- Не создавай вложенные `subscribe`; объединяй операции подходящим RxJS-оператором.
